# Paz Wash Locator (מאתר שטיפות פז)

אפליקציית ווב המאתרת את תחנות שטיפת הרכב של פז (Paz) הקרובות ביותר למיקומך הנוכחי בזמן אמת. 

## תכונות מרכזיות
- 📍 **איתור מבוסס מיקום:** מבקש גישת GPS ומאתר את הפריסה הגיאוגרפית של התחנות סביבך.
- 🚦 **מעבר מהיר לניווט:** כפתורי ניווט ישירים לפתיחת מסלול ב-Waze וב-Google Maps.
- 📱 **רספונסיבי ומהיר:** מותאם בצורה חלקה למכשירים ניידים.
- ⚡ **טעינה חכמה ב-iOS:** מחלק את הטעינה ל-15 תחנות בכל פעם ומפעיל צפייה עצלה (Lazy Loading) במפות כדי למנוע קריסות זיכרון בדפדפן ה-Safari ב-iPhone.
- 💾 **עדכון מידע אוטומטי:** קובץ התחנות מתעדכן באופן שוטף בעזרת פקודות סקריפט או שרת.

## טכנולוגיות
- HTML / CSS / Vanilla JavaScript.
- עיצוב Glassmorphism מודרני.
- חישוב מרחקים מבוסס על נוסחת Haversine (מרחק אווירי ישיר).

## שימוש
1. הפעל את קובץ ה-`index.html` בדפדפן מודרני (Chrome / Safari / Firefox).
2. אמשר גישה למיקום כאשר הדפדפן יבקש זאת (Location Permissions).
3. הרשימה תסתדר ותציג את השטיפות הקרובות ביותר בצורה אוטומטית.
4. לחץ על "טען תחנות נוספות" (Load More) כדי לצפות בתחנות המשך ברדיוס הרחוק יותר.
